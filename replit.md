# Woodyspaper

## Running the project

The runnable application is the React + TypeScript + Vite frontend in `Frontend/`.

- The **Start application** workflow runs `npm run dev` from `Frontend/`.
- Vite listens on `0.0.0.0:5000` so the site is available in Replit's web preview.
- Install dependencies from the `Frontend/` directory using its committed `package-lock.json`.

## Checks

From `Frontend/`:

- `npm run build`
- `npm run lint`
